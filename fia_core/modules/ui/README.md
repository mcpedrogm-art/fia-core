# UI/UX module — completo

This is the deliberately full module. It is not reduced to a checklist because
visual identity is a real part of the product for projects that need it.

It includes:

- input gate and Design DNA;
- four genuinely divergent visual directions;
- UX architecture, states, responsive behavior and accessibility;
- motion system with reduced-motion fallback;
- section recipes with a six-axis divergence matrix;
- conceptual tokens, originality review and validation deliverables;
- asset and licensing guidance.

Start with [UI_UX_EXCLUSIVA.md](UI_UX_EXCLUSIVA.md), then fill
[UI_RECIPES.md](UI_RECIPES.md). The pack also ships explicit opt-in commands:
`fia ui setup` (official pack, or `--recetas` for the recipe library only),
`fia ui status` (offline check) and `fia assets fetch <url|manifiesto>`.
Downloads are SHA-256 verified; see [UI_ASSETS.md](UI_ASSETS.md). The module is
still optional: enable it with `fia module enable ui` when the project needs it.
